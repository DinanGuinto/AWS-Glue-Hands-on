# AWS Glue – My Learning Journey

## 📖 Overview
I recently completed the **AWS Glue Getting Started project-based course** on Coursera.  
This hands-on training introduced me to AWS Glue, a powerful serverless ETL service.  
I gained practical experience building and running data transformation workflows using Glue Studio.

---

## 🎯 What I Learned
Through this course, I developed confidence in several key areas:

- **Understanding AWS Glue architecture** – I learned how Glue fits into the AWS data ecosystem and supports serverless ETL.  
- **Creating a Glue job in Glue Studio** – I built a visual ETL pipeline using the drag-and-drop interface.  
- **Connecting to data sources** – I configured connections to Amazon S3 and understood how Glue crawlers catalog data.  
- **Transforming data using built-in transforms** – I applied mapping, filtering, and renaming operations to shape the data.  
- **Running and monitoring Glue jobs** – I executed the job and reviewed logs and metrics to validate success.  
- **Exploring Glue Data Catalog** – I understood how Glue integrates with Athena and Redshift for downstream analytics.  

---

## 🛠 Hands-On Tasks
The project was structured around a guided workflow inside Glue Studio:

1. **Launch Glue Studio** – set up the workspace and explore the interface.  
2. **Create a new Glue job** – define source and target nodes, and configure transforms.  
3. **Connect to S3** – use sample data stored in S3 buckets.  
4. **Apply transformations** – clean and reshape the data using built-in tools.  
5. **Run the job** – execute the ETL pipeline and monitor its progress.  
6. **Review output** – validate transformed data and explore integration with Glue Data Catalog.  

---

## 🏆 Certificate
After completing the project and passing the final quiz, I earned a **Coursera Project Certificate**.  
This validates my ability to use **AWS Glue Studio for building and running ETL workflows** in a serverless environment.

This training gave me a solid introduction to **AWS Glue**, which is essential for scalable, serverless ETL in modern data engineering.
